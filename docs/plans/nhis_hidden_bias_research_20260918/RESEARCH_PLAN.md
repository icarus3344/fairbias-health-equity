# NHIS 隐藏亚组偏差：研究与实施总计划

日期：2026-09-18。状态：**PLAN_ONLY / DRAFT_NOT_FROZEN**。本文件是后续研究设计，不是新实验结果、已完成预注册或验证集开放许可。本轮只规划；未新增训练、个体数据分析或服务器任务。

## 1. 研究定位与可检验问题

从“证明 FairBias 比其他方法好”转向“识别常规公平性报告遗漏的模型差异，并检查这些差异是否稳定、能否改善”。面向医学信息学应用论文，优先利用已验收模型和预测。FairBias 保留为比较与机制案例，其失败和局限也可以成为结果；无须为了主方法身份继续增加训练预算。

暂定题目：**全国健康调查中医疗可及性预测的隐藏亚组差异：调查加权审计与跨年验证**。若验证未完成，题目中的“验证”应改成“探索性分析”。

必须区分三件事：
1. **健康服务差异**：某组自报因费用延迟就医的比例较高。
2. **模型表现差异**：在确有该结局的人中，某组更容易被模型漏掉；或者模型系统性低估该组的结局概率。
3. **因果歧视/干预伤害**：现有横断面观测和预测不能直接证明，需要额外设计。

当前结局 MEDDL12M_A 是既往自报费用相关延迟就医。把项目定位为离线识别与审计研究，不称已经用于临床决策，也不把回顾性分类写成前瞻预测未来就医。若拟用于支持需求识别，FNR 有直观意义，但这一用途仍需导师/领域合作者确认。

| 问题 | 主要证据 | 何时才支持结论 |
|---|---|---|
| Q1：单属性汇总是否遗漏了交叉群体较高的漏识别率？ | 边际组、性别×残疾四组、受限规则亚组的 FNR 与区间 | 报告绝对水平与差值；不能以边际“不显著”证明边际公平 |
| Q2：哪些差异跨年稳定，而非偶然的小样本信号？ | 2023 发现、2024 回顾性复核、候选 2025 独立时间验证 | 群体定义与模型在验证前冻结，完整报告未复现项 |
| Q3：现有单属性去偏是否改善或加重了未被约束的亚组差异？ | 相同人群、相同骨干、冻结模型之间的成对比较 | 区分“单属性训练后迁移到交叉组”和“直接训练交叉公平模型” |
| Q4：忽略调查设计、缺失语义会如何改变审计判断？ | 加权/未加权排序对照、设计区间、NIU/无应答分组 | 作为预设敏感性；不将排序改变自动解释为某估计错误 |

**优先级：Q1–Q3 为主线；Q4 为辅助。** 不同时展开因果发现、新几何算法、多重插补全管线和全模型重训。

“交叉群体可能不公平”本身已有成熟文献，不是创新。可争取的应用贡献是：在明确医疗可及性问题下发现有实质意义的特定亚组差异，给出调查设计不确定性、跨年复现和去偏迁移证据。文献核对前不得声称首次发现。

## 4. 模型、共同人群与输出适配

### 4.1 冻结模型面板

建议主发现模型：原 **Arm001 无干预 GBDT**，沿用原2023选择结果和原C阈值。这个推荐基于审计通用预测器的研究目的，不基于2024谁最容易产生显著亚组。R0核对实际 model_id、方法命名和覆盖后写入清单；本规划不虚构ID。

最小比较面板：
- 无干预 GBDT：主发现和主评价。
- 无干预 LR：骨干敏感性，不称独立样本复现。
- 同骨干 Reweighing、ThresholdOptimizer：主要改善对照。
- 同骨干 FairBias BM_AE、Joint：几何方法案例；不预设优越。
- OxonFair 可作补充；其他已完成方法可入描述性附表，但不扩充主要检验族或重新搜索最佳方法。

Arm001原本按性别训练/约束。用它审计残疾或交叉组回答的是“既有干预能否迁移到未被直接约束的人群”，不是所有方法已直接优化联合属性。Arm003残疾训练模型可作为**分开标明的敏感性**，先核对共同特征与人群，不拼接成一个混合模型。

沿用每个模型原有种子注册；有些LR对照只有seed0。对多种子报告**种子指标的均值及分散程度**；不选最好种子、不把5种子当5批独立受试者、不将平均概率后算AUC冒充原来的平均种子AUC。

### 4.2 记录级连接与共同域

- 原预测NPZ中有些只有数组，没有HHX。必须从绑定的原数据/纳入域重建记录顺序，并验证年度与域顺序哈希；相同行数不是对齐证据。
- 复用 completion_evaluation 的 domain_record_order_sha256、annual_record_order_sha256 及旧study身份映射。记录顺序错、重复ID或哈希不符即拒绝。
- 若2023个体预测未持久化，可在源/模型/环境核验后，仅用冻结模型补做推断并版本化；不得悄悄重训。
- 主比较共同域：结局和三项审计属性有效、且所纳入主模型均有预测的成年人。逐年报告纳排原因、未加权人数、权重质量及加权覆盖；该结果针对明确纳入域，不能自动推广到全部成年人。
- 保护属性缺失不插补成男性/女性/残疾等实体类别。额外报告因缺失被排除者的可得背景描述，说明完整案例选择局限。
- 上下文变量的NIU、无应答、其他缺失状态按原语义保留，可单独审计；不能把结构NIU一律称无应答。
- 同一规则的类别映射跨年固定，禁止每年分别factorize。稳定规则ID来自规范化规则，而不是排序名次。

### 4.3 p与q的硬边界

项目输出分开记录：
- p_event：结局风险概率，可用于AUC、Brier和概率校准。
- q_decision：最终决策/随机化为阳性的概率，可用于期望TPR/FPR/FNR等决策指标。
- base_p：部分后处理方法的原始模型概率，仅可明确标注为其底层模型概率。

禁止把q当p算“风险校准改善”；q-only方法风险指标为NOT_APPLICABLE。随机化q的FNR是策略随机化下的期望漏识别率，不能悄悄抽一次硬标签再与其他方法比较。所有阈值保持原C确定值。

## 5. 有界亚组发现：先简单，再判断是否需要复杂方法

### 5.1 第一层：预设分组

主预设结构：SEX_A × DISAB3_A 的4个组合，同时展示二者的边际组。族裔 HISPALLP_A 七组的交叉结构作为受支持度限制的补充；不预先承诺14/28组都能作正式EO训练。

原七组族裔C中已有一组仅1个阳性。将该组再拆两份后，不可能保证两份都有阳性，因此不能直接上完整14组EO校准。

### 5.2 第二层：有限且可解释的规则

允许保护属性：性别、族裔、残疾；允许背景维度优先为年龄、保险 NOTCOV_A、收入 RATCAT_A、就业路由/缺失状态。年龄分箱暂建议18–39、40–64、65+；这些是**待领域审阅的研究分箱**，不是临床标准。其他编码必须从官方字典形成对应表，不凭数值猜含义。

规则主线至少含一项保护属性、最多2个条件。仅背景变量构成的规则另列为性能切片，避免将所有高误差群体自动命名为歧视。禁止使用HHX、PSU、权重、模型输出、误差指示或结局本身定义群体。

第一实现：预设规则枚举 + 深度2的可解释树，最多500条主候选；树只在2023生成候选。分箱、搜索规模、排序、去重和输出上限先固定。若枚举数量超限，按预定模板缩减，不能按2024/2025表现截断。

探索性候选按2023加权FNR差值排序，支持度与规则简洁度作为预定的并列处理标准。主发现模型决定选择；禁止每个方法各挑一组然后互相比。完全相同成员集合的规则去重，等效规则优先条件少、再按稳定ID排序。重叠但非同一群体可保留并公开重叠矩阵。

正式验证列表为：4个预设性别×残疾组 + 最多10个发现亚组，去除完全重复项，故K≤14。预设组不因2023表现不佳而退出；支持不足者保留“不可作正式推断”的注册状态。所有搜索候选与失败记录留档。

### 5.3 可选第三层：MDSS Bias Scan

只有在前两层完成且需要补充更灵活的概率低估审计时增加MDSS。它是候选发现器，不是NHIS调查统计检验器。标准Bernoulli扫描使用p_event，不能输入后处理q冒充风险。默认软件的IID显著性不能直接当复杂调查p值。

本轮主计划不依赖MDSS才能交付。若采用，其搜索空间、选择数量及与主家族的关系必须在2025开放前冻结；否则只作后续探索，不回填主验证。

### 5.4 支持度建议

用于正式候选推断的默认提案：群体与比较补集各自n≥200、阳性≥30、阴性≥30、阳性/阴性Kish有效样本量各≥20、涉及PSU≥20。整体设计与分层覆盖另外检查。

这些是**保守的项目操作门槛，不是CDC统一标准，也不保证估计精确**。R1依据2023支持度、设计和领域需求确定最终门槛，必须在误差搜索及2025评价前固定。指标特定支持度不足时可以报告可估指标与区间，但不升级为主确认结论；不能删掉弱势小群体后声称“所有群体公平”。原始数、加权质量、设计区间均需公开到聚合表。

## 6. 端点与复杂调查统计

主端点为群体相对共同域补集的加权漏识别率差：
FNR(g) = sum[w·I(g)·y·(1−q)] / sum[w·I(g)·y]；
ΔFNR(g) = FNR(g) − FNR(not g)。正值意味着该组在已有结局者中更容易被漏掉。

每组同时展示FNR绝对值、TPR、FPR、BA、结局率、人口质量、n/n+/n−及设计支持；EO作为辅助汇总。高结局率不等于高FNR。加权漏识别人次可作模型推定的需求规模描述，但不是实际受害人数或可归因伤害。

风险附加端点仅对p有效的方法计算：加权mean(y−p)（正值为平均低估）、Brier、AUC及预先定义的校准图。平均残差为零不能证明完整校准；校准分箱从开发集确定、各年共用，不按验证数据重新挑分箱。

调查推断要求：
- 每年采用该年官方权重、层与PSU定义；域外贡献设零，保留完整年度设计信息。不能先把群体筛出来再当简单随机样本。
- 同一个人的多种子/多模型预测共享记录与PSU；采用同一批PSU重抽样做成对比较。不能只比较两个独立置信区间是否重叠。
- 新增FNR比率差的Taylor线性化与共同PSU bootstrap交叉校验。默认2000次重抽样、固定随机种子及输出有效复制比例；具体重抽样方案须依据官方设计说明与已有实现核对。
- Kish ESS只作权重离散度诊断，不替代聚类/分层方差。区间是条件于已训练模型的调查抽样不确定性；跨种子SD不是人口置信区间。
- 年度对照以各年区间和方向稳定性为主；无跨年抽样独立性证据时，不擅自作独立样本年度差检验或把重复PSU编码合并。
- 全程披露预测域覆盖、不可估指标、有限复制比例、稀疏组和非响应限制。RATCAT_A为发布的单次插补收入类别，不能推断原收入没有缺失；当前方案未传播收入多重插补不确定性。

正式检验：
1. 2025主家族：冻结K个亚组相对补集的ΔFNR，双侧检验零差异，Holm控制家族错误率；同时提供原始95%区间和明确标注的Bonferroni同时区间。不要把原始95%区间称为同时区间。
2. 2025次要家族：Reweighing、TO各自对K个群体的FNR变化，以及两方法的整体BA变化，计划2K+2个槽位。缺模型/不可估不缩小原注册家族；调整时p=1的占位与原始NA分开保存。
3. FairBias、LR、EO及校准比较先作为预设描述性/敏感性结果，不另挑显著性来宣传优越。若要升级正式主张，须在开放2025前登记检验族。
4. 2023搜索数据上的朴素p值不是发现有效性的证明；2024为回顾性证据。避免昂贵且无必要的“搜索后把同一数据再检验”。
5. 暂以5个百分点的FNR差作为优先讨论的效应规模，需R1确认。它不是已验证临床最小重要差异；点估计超过5个百分点且对零显著，不等于已证明真实差值大于5个百分点。

## 7. 改善实验与可解释性

第一轮**不新增训练**：比较已有RW、TO、FairBias等在同一冻结亚组上的迁移效果；同时看整体BA/FPR，不能以全面降低阳性预测换取表面差距变小。

若发现稳定且支持充分的群体，才考虑一个小的独立干预实验：性别×残疾联合四组Reweighing/TO vs 原单属性版本。先验证F/C每组两类支持与稳定性；相同训练数据、骨干、候选预算和C/S选择协议。新模型需在2025开放前完成并冻结。若等看过2025之后才修方法，新模型只能算后续探索，不能用同一2025证明独立优越性。

不默认新增联合FairBias训练；只有明确机制问题、可行支持和预算才作为第二项目。phi_threshold/NMI修正、序数保持、缺失语义保持都是新版本，不能改历史80模型或回填旧结果。

解释性图可以做，但回答不同问题：
- 亚组规则图：谁被遗漏，规则怎样从有限搜索得到。
- 边际与交叉热图：如何被总体平均掩盖，标上支持度和区间。
- FairBias最终映射图：哪些类别被合并，是否跨越NIU/无应答/实质状态。
- 同群体成对变化图：改善了哪个群体，是否损失整体效用。
- 不把几何图、SHAP、变换次数或合成XOR反例称作因果机制证明。

## 8. 实施阶段、验收与停止条件

所有阶段使用独立新输出根，原始数据和已验收产物只读。主管完成内部验收后可继续，不要求用户逐阶段确认。重大研究问题变更、不可逆发布和新增租用资源另行处理。

| 阶段 | 工作 | 可审查交付与准入 |
|---|---|---|
| R0 资产/数据可行性 | 核对当前文件与绑定清单；定位2023/2024预测；核查2025官方元数据和访问历史 | inventory.json、模型面板、年份可比性矩阵、未决项；不给2025自动赋予untouched |
| R1 研究与文献冻结 | 明确应用场景、变量语义、群体语法、支持门槛、端点、模型及检验族 | protocol_v1.json + 人读方案 + 文献矩阵；参数不再留TODO。尚不冻结未知的发现亚组列表 |
| R2 适配/合成验收 | 新的记录连接、稳定编码、p/q处理、亚组指标、调查推断与验证锁 | 有意义的边界测试、独立审查和小规模计时；真实数据运行前全部关键合同通过 |
| R3 2023发现 | 执行冻结候选搜索；保留全部候选；预设组+最多10发现组 | discoveries_v1.json、规则/模型/源哈希、搜索日志；之后不根据2024/2025替换发现列表 |
| R4 2024回顾性复核 | 对相同规则复核，检查跨年支持与效应；可选新干预在此完成 | 全部正负结果、改善对照；写明known_T=true。无法解释的新变更另列探索 |
| R5 2025准入与时间验证 | 合并冻结模型、发现列表、统计和release；一次批量评价 | 独立身份/数值核验、完整验证表、缺失/未复现记录；不存在“试跑后选好看的” |
| R6 论文包 | 汇总发现、机制边界、图表与规范，导师讨论材料 | 可复现表图、Methods/Results/Discussion、局限、代码发布待办与作者事实表 |

R2最低测试集合：
- 人造边际公平而交叉不公平的反例能被审计发现；无差异数据不因编码制造差距。
- 成员顺序随机打乱、重复记录、缺/未知类别、空组、零事件组、极端权重、域外PSU处理正确。
- q-only被风险指标拒绝；随机化决策期望计算正确；种子不会增加调查样本量。
- 比率差线性化与独立小样本手算/模拟一致；成对比较保留协方差。
- 未冻结/哈希变更/使用2025进行search或fit必须被程序拒绝；冻结后改变候选、阈值或检验族同样拒绝。
- 报告不静默删NA、缩小家族、混用模型版本；公开导出无个体记录。

停止/降级规则：
- 无可靠隐藏亚组：报告未检出、区间及可排除的效应范围；不扩展搜索直到显著。
- 群体太稀疏：描述性展示、说明统计盲区；不任意合并族裔或借用外组概率假装直接可估。
- 记录无法可信对齐：隔离对应模型/年份，不用行数或当前排序猜。
- 独立验证无法成立：降级为探索性研究，保留新验证需求；不把项目无限挂起。
- 域专家认为类别/用途不合理：在验证开放前修正并重新冻结；开放后修正保留为新版本及探索性结果。
- 基础合同失败只阻塞其依赖任务；文献、代码和汇报整理仍可推进，不反复重训已成功模型。

## 9. 论文结构与交付

建议正文：
1. Introduction：费用相关医疗可及性、单属性报告的遗漏风险、复杂调查与稳定验证缺口。
2. Methods：目标人群与结局、时间线、冻结预测模型、有限亚组发现、调查估计与多重比较、确认/探索边界。
3. Results：人群与支持度 → 边际/交叉差异 → 候选发现 → 时间复现 → 去偏迁移 → 调查/缺失敏感性。
4. Discussion：哪些具体人群受到模型遗漏、为何值得健康服务研究关注、哪种改善证据成立、哪些机制尚未知。
5. Limitations：标签与回顾性用途、未测医疗需要、样本支持、完整案例、收入插补、验证历史、计算/选择预算、非因果性。

主表：年度纳排与群体支持、冻结模型/输出类型、亚组发现与验证、成对改善与效用。
主图：研究时间线与纳排、边际/交叉差异图、所有冻结亚组跨年森林图、同群体方法变化图。
补充：完整候选注册、全部NA及理由、权重/设计敏感性、概率校准、FairBias语义映射与原始基准结果。
图形用可复现绘图工具导出PDF/SVG/PNG，标明单位、分母、区间、缺失；不使用生成式图片替代科学图。

新研究不应抹去旧FairBias工作：原完整结果作为既有方法评估资产，必要时单独方法审计稿。第一篇聚焦一个清楚的应用问题，避免两条主线都讲不完整。
