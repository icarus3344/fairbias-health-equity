## 1. Governance & Execution Principles

1. **No False Closure / No Unearned Passes**: Any check, regression test, or boundary condition that has not been executed and independently audited with verified test logs is marked `OPEN` or `UNVERIFIED`. It must never be marked `PASS` or `CLOSED`.
2. **Preservation of Verified Closures**: Issues successfully closed and verified in prior supervisor reviews retain their `CLOSED` status, but their scope is strictly circumscribed to the exact test cases verified. They are not conflated with broader open issues.
3. **Strict Gate Allocation Consistency**: Every open issue is allocated to a specific execution gate (Gate B1 for code correctness, Gate B2 for benchmark contracts/survey evaluation, Gate B3 for external adapters, Gate B4 for synthetic dress rehearsal, Gate B5/B6 for real execution).
4. **Concrete Counterexamples & Exact Formulas**: Every issue is mapped to explicit positive and negative counterexamples, exact code symbols, and verified line references.
