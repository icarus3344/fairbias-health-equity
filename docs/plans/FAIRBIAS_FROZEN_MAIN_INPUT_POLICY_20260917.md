监督登记：2026-09-17；在本轮任何真实 S 比较排名或新 T 评价之前固定。此文只接纳来源规则，不释放 T。完整研究释放仍须绑定选模产物、评价/统计/导出源码、真实年度输入哈希及监督 release。

## 注册分母与确定性来源规则

使用原注册表 SHA256 `340cd60f6ab0d5919e2ac7bc22b62bdb3cc758faaa986650abdb3978b964732a`，8,054 个注册 candidate×seed，1,922 个配置条目（包含不支持条件）。`pending_predeclared_extensions` 为空。注册表已经包含紧凑 CPU TabM、MLP、FairGBM base 预测器，不能将它们误称为未启动的缺口。TabICL-v1 与论文默认容量 TabM 明确不属于本轮注册候选。

- FairBias-BM：全部使用原预算、原版本，保留 198 项失败/预算终结，不用 22 项 MDS 扩预算结果替代。
- FairBias-BM→AE、Joint：主分析中的固定消融保留原版本全部终结状态。新 AE40、严格 Joint38 属于单独固定消融/敏感性证据，不按其成功与否混入原版本。
- FRAPPÉ：完整修正版本 480 项，来源为已验收的 CPU300、CPU80、迁移归档100，互斥、全覆盖。旧 69 项仅保留在历史尝试表中。
- LFR：完整数值优化版本 960 项，统一版本，不拼入旧模型。明确披露梯度/数值优化实现与停止规则，执行成功不称全局最优或原版逐位复现。
- EG-DP/EO：原版 1,513 个有效模型保留；原版失败的 23 个预先登记任务采用已验收数值恢复结果。映射由原运行的终结失败身份确定，不根据 S/T 性能。所有模型未来均使用同一冻结的 `EG_BOUNDED_PMF_V1` 推断规则。
- 其余方法及所有原有不支持条件保持注册表定义。每个注册任务必须显式映射到唯一 run；保留原始与恢复尝试，不按文件时间或最佳表现猜测来源。

完整种子规则、S 选择指标、阈值、tie-break 和固定消融容量保持原登记。没有完整有效种子集合的配置不得以剩余成功种子的均值参加比较。任何新版本都须在比较前声明，不从 T 结果决定是否纳入。

## EG 兼容接纳的证据和限度

1. 恢复适配器继承相同 `fit` 实现，修复作用于公平学习库输出的凸混合 PMF。原 23 个失败身份、完整源码/输入和恢复运行收据此前已独立核对。
2. 已审查的 helper 验证有限实数非负混合权重、权重和及两列 PMF 行和，容差为与混合项数相关的浮点舍入界。只纠正端点外的有界舍入误差，拒绝实质越界；不改变内部 q，不生成风险 p，不改变阈值，不抽样硬标签。
3. 原版 1,513 个有效模型的已保存 S q 与同一有界修复兼容，报告 SHA256 `321d977945e005e6fd7b6810ef867e8ea25ac046a9729daf394da18ffb2c134c`。这项检验只支持存储 S q，不证明未来输入或跨硬件训练逐位等价。
4. 正式冻结前对统一推断入口完成生成数据测试：原版/恢复版 EG、DP/EO 身份、p/q、长度、未拟合、无重拟合、端点修复与实质越界拒绝。将入口源码哈希绑定 study。
5. 在真实 T 上发生新的数值/语义错误时，不根据性能替换模型、裁剪任意输出或另选配置；原错误保留，技术修复必须保持冻结候选与分析定义，并记录新的执行身份。

监督兼容 gate 必须绑定新目录、注册表、逐任务来源映射、同一预算、方法版本与证据哈希。目录中将 EG 恢复由 pending 标为 replacement，只表示来源证据已满足；不会自动授权 S 选模或 T 评价。

## 独立固定预算敏感性

AE40 的完整矩阵已验收 38 有效、2 预算耗尽，原先 19 个有效任务全部重新拟合；使用单独研究分支和全部原注册种子。严格 Joint38 及未进入重跑的 2 个原 MDS 预算失败保留各自状态；BM MDS22 不构成完整增强预算主矩阵。不得把这些版本的成功种子补入主分析。

这些附加分支的配置及预算在主分析 T 之前已固定，不因主分析结果新增或删除。正式评价前仍需各自完整来源、固定配置、种子与分析源码冻结；在当前主分析 freeze 中明示其身份及状态，报告分开呈现。主分析可正常报告原预算失败，不宣称附加研究已经完成。
