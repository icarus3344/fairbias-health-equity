## 2. Erratum 1: Reclassification of `runs/d8_enhancement_study/d8_enhancement_study_results.json`

### 2.1 Superseded Claim
In the Gate D8-R4B report (`docs/reports/NHIS_D8_R4B_FINAL_EVIDENCE_RECONCILIATION_20260909T092500Z_d8r4b_reconciliation.md`), `runs/d8_enhancement_study/d8_enhancement_study_results.json` was cataloged alongside three other files as part of a four-file "authoritative primary model output" set produced by the R4 execution.

### 2.2 Corrective Evidence
Independent verification against repository Git history confirms that this file predated the Gate D8-R4 run:
- **File path**: `runs/d8_enhancement_study/d8_enhancement_study_results.json`
- **File size**: `26,751` bytes
- **SHA-256**: `944df70bd75a8c1a1bb0c6758540936123582fcab08bc64d5806583f09e4da11`
- **Historical origin**: Recorded in the pre-repair manifest at `2026-09-08T06:11:31Z` (prior to Gate D8-R1 repair and prior to R4 execution).

Because this file existed with the identical content, byte count, and SHA-256 hash prior to R4 execution, it was not generated by the R4 primary run.

### 2.3 Authoritative Correction
The authoritative primary model output set for Gate D8-R4 contains exactly three (3) files, all successfully generated and written prior to the Step-11 `KeyError` exit in R4:
1. `artifacts/nhis_d8_r4/20260909T080325Z_d8r4_substantive/condition_metrics.json`
2. `artifacts/nhis_d8_r4/20260909T080325Z_d8r4_substantive/primary_deltas.json`
3. `artifacts/nhis_d8_r4/20260909T080325Z_d8r4_substantive/joint_trajectory_events.json`

The file `runs/d8_enhancement_study/d8_enhancement_study_results.json` is formally reclassified:
- **Status**: `PRE_EXISTING_LEGACY_D8_OUTPUT`
- **Designation**: `NOT_R4_PRIMARY_OUTPUT`

**Scientific impact**: Zero. Complete C1–C4 condition metrics, primary delta contrasts, and C4 joint trajectory logs are fully preserved within the three verified primary artifacts. This issue is cataloged as a residual P2 provenance labeling defect with zero release impact.

## 3. Erratum 2: Descriptive Sensitivity vs. Causal Interpretation in Arm 4

### 3.1 Superseded Statement
Section 7.3 and Section 8.3 of the D8-R4B reconciliation report contained the statement:
> *"The apparent 0.7520 AUROC disappeared because it was an artifact of unconstrained bias in an infeasible regime."*

### 3.2 Corrective Evidence
Empirical evidence shows that:
- In exploratory R3 (engineering geometry), Arm 4 (`D6_ARM_004`, DISAB-exclude) reached a test AUROC of `0.7520` in a state that did not meet the frozen D6 fairness criterion.
- In primary R4 (paper-faithful Tang 2024 / stress-elbow geometry), Arm 4 C4 reached a test AUROC of `0.6866` while meeting the frozen D6 fairness criterion ($\Delta\text{AUROC} = +0.0196$ over C2 test AUROC `0.6670`, with baseline `0.7353`).
- While terminal states, step counts, and constraint feasibility differed substantially between the two runs, concluding that the higher AUROC in R3 was causally an "artifact of unconstrained bias" exceeds available evidence without dedicated mechanistic ablation experiments.

### 3.3 Authoritative Replacement
The causal phrasing is superseded by the following descriptive interpretation:
> "The large Arm-4 engineering-geometry C4 gain did not replicate under the primary paper-faithful geometry. The engineering trajectory was not feasible under the frozen D6 fairness criterion, while the primary trajectory reached the criterion, indicating strong geometry/path sensitivity."

**Scientific impact**: This formalizes the core scientific findings of Gate D8:
1. **C3 Posthoc Mitigation is path/geometry-robust**: All 4 arms yield identical terminal states and AUROC values across both paper-faithful and engineering geometries ($\Delta\text{AUROC} = 0.0000$).
2. **C4 Joint Interleaving is strongly geometry/path-sensitive**: Trajectories diverge across geometries for HISP, DISAB-full, and DISAB-exclude.
3. The primary paper-faithful geometry under frozen D6 thresholds is the canonical, authoritative finding. Historical R3 engineering results serve as exploratory sensitivity analyses highlighting the criticality of replication fidelity for geometry-dependent optimization algorithms.
